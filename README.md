# Midnight Reminder Pi Extension

A Pi extension that reminds users at midnight.

## Setup

This project uses TypeScript and Vitest for testing.

## Scripts

- `npm test` — Run tests with Vitest
- `npx tsc --noEmit` — Type-check without emitting files

## Structure

- `src/` — Source code
- `tests/` — Test files
- `.pi/extensions/` — Pi extension files
